# CPP09

42 School C++ Module 09 — STL containers in practice: Bitcoin exchange lookup, RPN calculator, Ford-Johnson sort.

## Concepts covered
- BitcoinExchange: parsing and looking up historical exchange rates
- RPN: a reverse Polish notation calculator
- PmergeMe: the Ford-Johnson (merge-insert) sorting algorithm on vector and deque

## Exercises
ex00 ex01 ex02 

## Build & run
Each exercise has its own Makefile:
```sh
cd exXX
make
./<binary_name>
```
`ex00` needs `data.csv` (exchange-rate database, included) in its working directory, e.g. `cd ex00 && make && ./btc input.txt`.
